# Guion de Natfy

Este archivo contiene únicamente el bloque del proyecto propio. La presentación y los documentos del asignado continúan en https://github.com/Samuel-Hdzx07/Proyecto-Asig-Sismos.

1. Explicar Natfy como red social musical con colaboración y tienda.
2. Mostrar el EER en Chen y Crow’s Foot. Abrir el SVG o draw.io para ampliar.
3. Ejemplificar usuario con roles opcionales, jerarquía de audio y una entidad débil.
4. Justificar las consultas de playlists, versiones de proyecto y recomendaciones.

El bloque propio ocupa aproximadamente dos minutos dentro de la exposición completa indicada por la práctica. La presentación independiente permite ampliar explicaciones durante preguntas.
